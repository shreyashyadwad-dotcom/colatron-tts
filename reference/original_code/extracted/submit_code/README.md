# CS229 Fall 2018 Project #
#End-to-end Text to speech synthesis#

This zip folder includes our three training models.
Training folder includes example training text input and spectrogram output.
LJSpeech.py is for reading dataset from given path and addressing single utterance audio/text pair.
cmudict.py is to loop up corresponding for our text input.
params_dict.py is for storing hyperparameters for audio processing.
audio.py is the self-defined library for necessary audio processing.

One file in SVR model: svr_tts.py includes parts of preprocess data, svr model training, and postprocess part.
One file in NN model: simple_neural_network_tts.py includes parts of preprocess data, svr model training, and postprocess part.

Three files are in seq2seq folder: preprocess.py is for preprocess data before training, train.py is the seq-2-seq with attention model, eval.py is for model evaluation.

The wav file generated from the model is stored as test_wave.wav

In the main methods of our training models, we already give an example input. A wav file could be generated by running our model file (svr_tts.py,simple_neural_network_tts.py,eval.py).
However, in accordance with submission requirement, only part of libraries and a few training data included are included in this zip. The files couldn't not be executed successfully.
